# Совместимость пака со всеми версиями (1.19.2 … 26.x, Horizon)

Запуск на распакованном паке:

    python3 tools/fix_pack.py <папка>
    python3 tools/png_repair.py <папка>

- `fix_pack.py`: ссылки моделей `ia:N` → настоящие пути текстур (старые версии без оверлеев и Horizon не понимают алиасы атласа), атласы переписаны на настоящие пути; повороты элементов нового формата (x/y/z, ±90, 19°) → старый формат; pack.mcmeta с format 9 (1.19.2).
- `png_repair.py`: ItemsAdder «защищает» PNG битыми CRC/adler32 — ванильный клиент это терпит, Horizon и любые строгие декодеры нет. Скрипт пересобирает PNG в чистый 8-bit RGBA.

Если пак когда-нибудь заново собирать из ItemsAdder (generated.zip), прогнать оба скрипта ещё раз.
